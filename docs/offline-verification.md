# 桌面本机版无需 VPN 的验证

2026-10-13，Windows、Node.js 24.19.0、Windows PowerShell 5.1。交付桌面入口为「下一步.lnk」，打开 `http://127.0.0.1:8787/?mode=local#/home`。

## 启动与安全

- 原在线快捷方式已备份到 `.data/desktop-shortcut-backup/`，验证新的目标及参数后才移除旧入口。
- 冷启动隐藏运行本机服务，不安装依赖、不重新构建。再次启动及并发启动复用已有健康服务；缺少运行文件和端口冲突返回明确错误，不结束其他程序。
- `/api/health` 仅返回应用标识和就绪布尔值，保留 Host/Origin 校验，不需要配对，不调用 Codex 或 GitHub。
- 新启动的桌面服务通过 `--local-desktop` 暂停后台扫描和 AI 解释，原设置、个人来源、作者和队列保留。普通入口显式开启自动发现后可以恢复。复用普通入口已运行的服务时，后台沿用它原来的状态。
- 经 Windows Shell 实际启动桌面快捷方式，服务持续运行在 `127.0.0.1:8787`；未绑定外网或局域网地址。

## 浏览器离线操作

Browser plugin not available，使用运行环境已有的 Playwright 和隔离 Edge 浏览器，不读取用户账号资料。拦截并拒绝所有外网请求，仅允许回环连接。

- 全新浏览器首次载入当前交付的完整能力快照，真实原文、内容哈希与中文解释逐条对照一致。
- 推荐榜、高星榜、20→40、用途筛选、英文搜索和收藏通过。
- 需求澄清、30 秒竖屏视频流程、复制具体提示词、步骤完成、增量进度和刷新恢复通过。
- 即使模拟已有 ChatGPT 配对、保留 `preferAI=true`，本地入口的任务和 Skill 导入也没有请求 AI 理解接口。手动中文解释与个人能力导入通过。
- 导出备份并恢复到新浏览器，原始需求、步骤 ID、参数、完成状态、收藏和个人能力完整保留。使用与在线导出相同的版本化备份格式，不自动迁移其他 origin 的数据。
- 显式获取联网目录时模拟网络失败，现有目录与数据保持可用。切回普通本机入口后，保存的数据和原 AI 偏好保持。
- 1440、390、320 像素宽度均无横向溢出，页面有明确“正在使用本地推荐”提示，无相关控制台或运行时错误。

## 重启和检查

独立持久浏览器先恢复备份并关闭。只重启本次验证所启动的桌面服务，然后重新打开该浏览器；任务 ID、参数、完成步骤、个人导入与收藏逐项一致，已完成视频的任务继续停在字幕步骤。该过程没有外网请求。

`pnpm test` 的 81 项检查、TypeScript 检查和 Vite 生产构建通过。生产目录包含本机 HTML、JS、CSS、图标及完整公共能力快照。

验证保证当前电脑的核心功能无需 VPN，不代表实时 Codex AI、GitHub 最新检查、在线 Sites 登录或外部 Skill 服务可以直连。未购买 API、托管套餐或额外额度。
