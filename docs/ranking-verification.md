# 推荐榜验证记录

2026-10-12；Windows、Node.js 24、React/Vite；Browser plugin 不可用，采用 bundled Playwright 和隔离 Microsoft Edge，不读取用户浏览器资料。

`src/core/SkillRanking.ts` 提供推荐与仓库星数两种排序；`src/features/Ranking.tsx` 为桌面侧栏和手机“更多”的独立页面。榜单只使用已解释的真实 Skill，排除连接器、待确认、来源移除和停用项目。同英文名多来源在榜中显示一次，目录、原始文档和流程步骤不被删除。

推荐排序使用通用任务的人工用途权重、维护状态和有上限的仓库热度；高星排序严格使用快照里的 `githubStars`。该数从真实 GitHub source 元数据映射，并由后续扫描更新，是所属仓库星数，不是 Skill 使用人数。来源不明、缺失、负数、非整数以及手工导入或内置摘要自填的星数不纳入高星榜；真实零星数不被改写成缺失。

8 项排行自动检查通过，覆盖推荐适用性、未知用途过滤、仓库热度排序、缺失数据、同英文名去重、维护状态、口语及分类搜索、稳定名次和分页。另一个目录检查实际走模拟固定提交扫描→更新星数→保留原中文解释→备份恢复，验证了元数据更新不会丢失人工说明。全套 69 项检查通过，TypeScript 检查通过。
