# 高星来源与中文目录整理

2026-10-11 的真实 GitHub 快照共 470 个 Skill，全部保留原始 Markdown、固定提交链接、来源路径和内容哈希。本轮逐条根据原始名称、描述和正文理解用途，438 项完成中文名称、用途、分类、标签和口语搜索词；32 项只有通用连接流程或属于空模板、测试夹具，保留中文预览和待确认原因，不强行推荐。

这次整理使用开发对话中已经取得的资料，没有购买 API，也没有额外启动 Codex 理解调用。预置的 45 个已核实 Skill 与 4 类连接器继续保留；目录收录不表示插件已安装或服务已授权。

GitHub 热门发现对固定主题查询按 stars 排序，合并去重后再次按真实 star 数排序；每次巡检优先官方来源，并为其他热门仓库保留文档预算和断点轮转。公开目录提供全部技能原文；大型扫描树游标保存在 `.github/catalog-scan-state.json`，仅巡检使用。分离后含中文的快照约 5.4 MB，网页不再下载约 10 MB 的树游标。

真实 YAML 名称含空格或开头连字符时仍保留，修正了 8 个被误写为 imported-skill 的名字。复制提示词只对有效名称使用 `$SkillName` 写法，其余引用真实名称和原始来源路径，不伪造插件。

需要外部账号、Rube、API key、云实验或第三方服务的能力记录真实前置条件；这些能力不能自动替代普通本地文件任务。原文变化后重新进入解释队列，同一内容哈希的中文说明继续保留。未取得的仓库、未完成的扫描和未知用途不会标成已完成。

可运行检查见 `tests/catalog.test.ts`、`tests/public-scan.test.ts`。实际浏览器搜索与同步结果见 `production-verification.md`。
