# 高星来源与中文目录整理

首次 2026-10-11 的真实 GitHub 快照共 470 个 Skill，逐条理解后有 438 项完成中文整理；32 项通用连接流程、空模板或测试夹具保留待确认。2026-10-13 合并持续巡检与高星补扫后，当前目录为 1159 条，全部保留原始 Markdown、固定提交链接、来源路径和内容哈希。

已逐条阅读和整理的 824 条中，774 条用途明确并完成中文名称、用途、分类、标签和口语搜索词，50 条属于路由、模板或依赖不明确的参考说明，保留中文预览与原因。另有 335 条是后续巡检新发现的原文，进入本机解释队列，每天默认最多解释20条；没有将尚未处理的文档强行标成可推荐。目录规模会随真实巡检变化，这不是 GitHub 全部插件的名单。

高星补扫实际取得 Superpowers 15/15、Matt Pocock Skills 38/38、ECC 40/1062；前两项完整成功，ECC 保存固定提交和游标继续扫描。Remotion 的12份原文发生哈希变化后重新读取、核对 Git blob SHA-1并解释；路由入口保留参考，音视频信息查询不再误写为素材编排，素材和配乐流程使用真实 `remotion-markup`。已有任务的已完成步骤和独立ID保留，尚未执行的旧错误调用会更新。

这次整理使用开发对话中已经取得的资料，没有购买 API，也没有额外启动 Codex 理解调用。预置的 45 个已核实 Skill 与 4 类连接器继续保留，内置摘要版本更新为 `catalog-2`，浏览器与本机服务会更新旧摘要而保留个人导入。目录收录不表示插件已安装或服务已授权。

GitHub 热门发现对固定主题查询按 stars 排序，合并去重后再次按真实 star 数排序；每次巡检优先官方来源，并为其他热门仓库保留文档预算和断点轮转。公开目录提供全部技能原文；大型扫描树游标保存在 `.github/catalog-scan-state.json`，仅巡检使用。2026-10-13 的含中文快照为 12,619,537 字节，扫描游标为 35,500,839 字节；网页只下载能力快照，不下载树游标。

真实 YAML 名称含空格或开头连字符时仍保留，修正了 8 个被误写为 imported-skill 的名字。复制提示词只对有效名称使用 `$SkillName` 写法，其余引用真实名称和原始来源路径，不伪造插件。

需要外部账号、Rube、API key、云实验或第三方服务的能力记录真实前置条件；这些能力不能自动替代普通本地文件任务。原文变化后重新进入解释队列，同一内容哈希的中文说明继续保留。未取得的仓库、未完成的扫描和未知用途不会标成已完成。

可运行检查见 `tests/catalog.test.ts`、`tests/public-scan.test.ts`。实际浏览器搜索与同步结果见 `production-verification.md`。
